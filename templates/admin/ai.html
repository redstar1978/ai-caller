Spracherkennung (STT – Speech-to-Text)
Lokal: faster-whisper (OpenAI Whisper, CPU-optimiert)
Das Modell wird beim ersten Start automatisch heruntergeladen.
  • tiny – sehr schnell (~75 MB)
  • base – gut ausgewogen (~150 MB, empfohlen)
  • small – genauer (~500 MB)
  • medium – sehr genau (~1,5 GB)
  • large-v3 – beste Qualität (~3 GB)
Cloud: OpenAI Whisper API (oder kompatibel)
Kompatibel mit OpenAI, Groq (kostenlos!), Deepgram, AssemblyAI u.v.m.
Groq: kostenlosen API-Key unter console.groq.com erstellen.

Google Cloud Text-to-Speech
Kostenlos 4 Mio. Standard-Zeichen/Monat oder 1 Mio. WaveNet/Neural2-Zeichen/Monat (dauerhaft).
Anleitung zum API-Key:
  1. Gehe zu console.cloud.google.com und erstelle ein Konto (Kreditkarte nötig)
  2. Neues Projekt erstellen → APIs & Dienste → Bibliothek
  3. Suche nach „Cloud Text-to-Speech API" → aktivieren
  4. Abrechnung aktivieren (für Free Tier keine Kosten bei Einhaltung der Limits)
  5. APIs & Dienste → Anmeldedaten → Anmeldedaten erstellen → API-Schlüssel
  6. Key kopieren und hier einfügen
Neural2/WaveNet: 1 Mio. Zeichen/Mo kostenlos
Cloud: OpenAI TTS API (oder kompatibel)
Kompatibel mit OpenAI, LocalAI und anderen OpenAI-kompatiblen Diensten.
Anleitung OpenAI API-Key:
  1. Konto erstellen auf platform.openai.com
  2. API Keys → Create new secret key
  3. Key kopieren (beginnt mit sk-…) – wird nur einmal angezeigt!
  4. Guthaben aufladen unter Billing (kein kostenloses Kontingent für TTS)
Microsoft Azure Speech Service
Kostenlos 500.000 Zeichen/Monat im Free-Tier (F0).
Anleitung zum API-Key:
  1. Gehe zu portal.azure.com und erstelle ein kostenloses Konto
  2. Klicke auf Ressource erstellen → suche nach „Speech"
  3. Wähle Preisstufe Free F0 und eine Region (z.B. westeurope)
  4. Nach Erstellung: Schlüssel und Endpunkt → Key 1 kopieren
Muss zur Ressource passen
ElevenLabs – hochwertige KI-Stimmen
Kostenlos 10.000 Zeichen/Monat im Free-Tier.
Anleitung zum API-Key:
  1. Konto erstellen auf elevenlabs.io
  2. Oben rechts auf das Profilbild → Profile + API key
  3. API Key kopieren (beginnt mit sk_…)
  4. Voice-ID: Gehe zu Voice Library → Stimme auswählen → ID aus der URL kopieren
Rachel (EN) = 21m00Tcm4TlvDq8ikWAM (Beispiel)
Höher = stabiler, weniger expressiv
Höher = ähnlicher zur Original-Stimme
Sprachmodell (LLM – Large Language Model)
Lokal: Ollama (vorhandener Server)
Ollama muss separat installiert und gestartet sein: https://ollama.com
Modelle installieren z.B. mit: ollama pull llama3 oder ollama pull mistral
Läuft Ollama auf diesem Server: Standard-URL http://localhost:11434 verwenden. Läuft Ollama auf einem anderen Rechner im Netzwerk: Netzwerk-Suche verwenden.
  • Erst Netzwerk scannen oder Verbindung testen
Muss in Ollama installiert sein.
Gefundene Ollama-Server:
Kein Ollama-Server im Netzwerk gefunden. Ist Ollama gestartet? Überprüfe ob der Dienst läuft: systemctl status ollama
